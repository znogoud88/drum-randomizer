# Drum Randomizer

Страница для барабанных занятий: четыре большие кнопки HANDS, FEET, FILLS, SONGS. Нажимаешь, и страница берёт случайное упражнение из категории и играет его по кругу с нотами и ползунком темпа.

Сайт: **https://znogoud88.github.io/drum-randomizer/**

## Как пользоваться

- `1`–`4` или большие кнопки: случайное упражнение из категории, сразу играет по кругу.
- `Пробел`: играть или пауза. `←` `→`: темп на 5 BPM.
- Темп запоминается для каждого упражнения отдельно, в браузере этого компьютера.
- «Барабаны в звуке» выключает барабанную дорожку: можно играть под остальные инструменты, если они есть в файле.

## Как добавить упражнение

### 1. Подготовить файл в Guitar Pro

1. Открой песню или упражнение в Guitar Pro 8 и сделай **Сохранить как** под новым именем.
2. Удали такты до и после нужного куска. Страница играет файл целиком и по кругу.
3. Проверь, что отметка темпа стоит в **первом такте**. Если вырезал кусок из середины песни, отметка могла уйти вместе с удалёнными тактами, и страница покажет 120 BPM.
4. Другие инструменты можно оставить: на экране видна только барабанная дорожка, в звуке играет всё.
5. Сохрани как `.gp`. Подходят также `.gpx`, `.gp5`, `.gp4`, `.gp3`. Имя файла станет названием упражнения.

Оригиналы удобно держать в `Documents\music\guitar-pro\tabs\to-randomizer\<категория>`.

### 2. Загрузить на GitHub

1. Открой нужную папку: [hands](https://github.com/znogoud88/drum-randomizer/upload/main/exercises/hands), [feet](https://github.com/znogoud88/drum-randomizer/upload/main/exercises/feet), [fills](https://github.com/znogoud88/drum-randomizer/upload/main/exercises/fills), [songs](https://github.com/znogoud88/drum-randomizer/upload/main/exercises/songs). Эти ссылки сразу открывают загрузку в папку. На сайте они есть в блоке «Упражнения».
2. Перетащи файлы, можно несколько сразу.
3. Нажми **Commit changes**.
4. Подожди около минуты и обнови сайт. Ход сборки видно на вкладке [Actions](https://github.com/znogoud88/drum-randomizer/actions).

Нужно быть залогиненным в GitHub как `znogoud88`. Для занятий логиниться не нужно, сайт открывается на любом компьютере.

### Удалить или переименовать

Открой файл в папке `exercises/<категория>`, меню `⋯` справа сверху, **Delete file** и **Commit changes**. Чтобы переименовать, нажми карандаш и поменяй имя в поле пути. Запомненный темп у переименованного упражнения сбросится.

## Если что-то не так

- **Упражнение не появилось.** Проверь вкладку Actions: последняя сборка должна быть зелёной. Обнови сайт с `Ctrl+F5`.
- **Ноты не нарисовались или ошибка при открытии.** Пересохрани файл в Guitar Pro 8 как `.gp` или экспортируй в `.gp5`.
- **Темп не тот.** Смотри шаг 3 про отметку темпа.
- **Нет звука.** Звук включается после первого нажатия на странице. Если сверху красная надпись, обнови страницу.

## Устройство

- `index.html` — вся страница. Ноты и звук делает библиотека [alphaTab](https://github.com/CoderLine/alphaTab) 1.8.4.
- `exercises/<категория>/` — файлы упражнений.
- `scripts/build-manifest.mjs` — собирает `exercises.json` из папок. Запускается автоматически при каждом коммите (`.github/workflows/pages.yml`).
- `vendor/` — нотный шрифт Bravura (лицензия OFL) и звуковой банк Sonivox (Apache 2.0).

Запуск у себя: `node scripts/build-manifest.mjs`, потом `node scripts/serve.mjs` и открыть http://localhost:5178.
